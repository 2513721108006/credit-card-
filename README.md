Credit Card Default Prediction -- Machine Learning Project

Project Overview

- This project predicts whether a credit-card customer is likely to default on the next month's payment using machine learning.
  
Dataset

- The dataset contains 30,000 customer records with information such as credit limit, age, repayment status, bill amounts, and payment amounts.

Target: default payment next month (default / no default).

Tools Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
  
Project Steps

1. Load and clean the dataset.
2. Perform statistical analysis.
3. Handle missing values and duplicates.
4. Detect and cap outliers.
5. Encode features and separate input and target data.
6. Visualize the data.
7. Split data into training and testing sets.
8. Apply feature selection and standardization.
9. Train and evaluate machine-learning models.
    
Machine Learning Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
  
Evaluation Metrics

- Accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrix.
  
How to Run

1. Keep creditcard.csv in the notebook's working folder.
2. Open creditcard ml project.ipynb in Jupyter Notebook.
3. Run the cells in order.
   
Goal

- Compare the models and identify a suitable model for predicting
credit-card payment defaults.
